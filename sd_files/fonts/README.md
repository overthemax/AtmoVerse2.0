# Font Numeri Corsivo 32x48

Questa cartella contiene i file BMP 1-bit per i numeri in stile corsivo elegante.

## File inclusi:
- `0.bmp` - `9.bmp` → Cifre
- `dot.bmp` → Punto decimale (.)
- `colon.bmp` → Due punti (:)
- `degree.bmp` → Simbolo grado (°)

## Specifiche:
- **Dimensione**: 32x48 pixel
- **Formato**: BMP 1-bit (bianco/nero)
- **Stile**: Corsivo minimale elegante

## Utilizzo nel codice:
```cpp
// Esempio di caricamento
drawBmpFromSD("/fonts/0.bmp", x, y);
```

## Note:
I file BMP devono essere generati con un editor grafico (GIMP, Photoshop, ecc.) 
e salvati come BMP 1-bit monocromatico.
